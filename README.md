# Assignment 4 — Forms and Validation

## Description
This project was created for Web Technologies Assignment 4. It demonstrates HTML forms, HTML5 validation, Bootstrap form styling, and JavaScript validation.

## Tasks
- **Task 0:** Simple Contact Form with name, email, and message.
- **Task 1:** Contact Form with HTML5 Validation.
- **Task 2:** Contact Form styled using Bootstrap 5 and Bootstrap Grid.
- **Task 3:** Bootstrap Validation with success and error feedback.
- **Task 4:** Registration Form with personal information, password confirmation, radio buttons, checkboxes, and country selection.

## Technologies
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## How to Run
Open `index.html` in a browser or use Live Server in Visual Studio Code. Use the navigation bar to switch between tasks.
